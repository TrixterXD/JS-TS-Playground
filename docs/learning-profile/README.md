## How to use the profile

- Check prerequisite knowledge before authoring a task; validate uncertain concepts rather than assuming mastery.
- Prioritize independent decomposition, input/output understanding, intermediate data, processing order, invariants, and edge-case reasoning.
- Treat prior practical framework exposure as evidence of exposure, not proof of deep understanding.
- Distinguish the initial audit from later observed learning. Assessments are starting points, not permanent labels.

Future audits can be added as dated files in this directory. Record their date and evidence, and document which assessment represents the current profile without replacing the historical initial audit. Update authoring guidance as warranted. No change to the scaffolding generator is needed: it creates neutral templates and deliberately contains no skill assessments or exercise-content generation.
